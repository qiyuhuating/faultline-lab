# ADR 003 — Publish evidence playback, keep execution local

Status: accepted.

A portfolio should be inspectable without installing software, but a public anonymous worker-killing endpoint is a different operational product. We publish a static trace player on GitHub Pages and keep the control room bound to 127.0.0.1.

The six records are generated by real HTTP submissions and independent OS processes. A lost-response experiment deliberately destroys the response only after the request is durable. The player labels every view RECORDED, NOT LIVE, verifies the retained hash chain using WebCrypto, compares displayed events with their verified originals, and recomputes the same acceptance assertions used by the server.

Playback has no task-submission API. Each frame projects a persisted event sequence; it does not implement another scheduler or secretly fabricate a success. A modified chain disables playback. A hash chain establishes consistency, not independent authenticity: a database owner can recompute it.

The publishing workflow waits for the verification workflow to succeed on main and publishes that exact verified commit. Source, tests and hosted files have separate packaging boundaries.
